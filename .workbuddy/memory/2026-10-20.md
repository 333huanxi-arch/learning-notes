# 2026-10-20 工作日志

## learning-notes 项目：接入 docsify-sidebar-collapse 插件

- 背景：用户反馈 Docsify 生成的网站侧边栏（目录）有问题，要求加入 docsify-sidebar-collapse 插件。
- 插件文件下载到本地 `vendor/`（项目原本就走本地资源路线，保持离线可用）：
  - `vendor/docsify-sidebar-collapse.min.js`（插件，4730 字节）
  - `vendor/sidebar-folder.min.css`（文件夹图标样式，当前启用）
  - `vendor/sidebar.min.css`（箭头样式，备选，未引用）
- 修改 `index.html`：
  - 引入 `sidebar-folder.min.css`；
  - `$docsify` 增加 `alias: {'/.*/_sidebar.md': '/_sidebar.md'}`（否则进入 books/ 等子目录页面时侧边栏会加载失败——这是"目录有问题"的主因之一）；
  - 增加 `sidebarDisplayLevel: 1`（默认只展开第 1 级，更深层级点击展开；该配置由插件读取，docsify 4.13.1 本身不支持此键）；
  - 插件脚本放在 `docsify.min.js` 之后加载。
- 环境备注：本沙箱内 localhost HTTP 被网络层拦截（node/PowerShell 均返回 403 "forbidden"），无法在沙箱内截图验证；本地 docsify 版本为 4.13.1；bash 工具 PATH 损坏（dirname/ls 不可用），命令输出不回显，需写文件再读。
- 验证方式：通过 present_files 的 localhost 预览（沙箱外层）查看效果；临时服务器脚本验证后已删除。
- 环境限制（重要，后续会话可复用）：本沙箱内 localhost HTTP 被网络层拦截，node/PowerShell/内置预览浏览器访问自建服务器（如 8517 端口）均返回 403 "forbidden"（小写，9 字节）；内置「静态文件回退预览」只提供 index.html 中引用过的文件，Docsify 这类靠 XHR 动态加载 .md 的站点在其中必然 404（侧边栏和内容都空）。结论：沙箱内无法对 Docsify 站点做实时预览，只能交付代码 + 告知用户在沙箱外用真实静态服务器验证。
- 项目约定（重要）：Docsify 侧边栏完全由根目录 `_sidebar.md` 手动维护，不扫描目录；新笔记放进去后必须在 `_sidebar.md` 挂链接才会显示。本次为 `books/ux/universal-principles-of-ux/notes/2026-10-20.md` 补了侧边栏条目（用户已自行在书 README 的「章节笔记」补了链接）。`_sidebar.md` 中每日汇总和模板两段被 `<!-- -->` 注释掉，故不显示，需要时取消注释即可。
